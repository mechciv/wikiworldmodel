How the atlas measures coverage

The full index includes every polity and named border run in the selected build, selected records for settlements and cultural practices, and a small reference chronology. The timeline opens on highlights. Search draws from the full index. Counts refer to entries in this atlas.

Solid marks show dated model records. A single date appears as a point. Striped marks show years with mapped borders in Cliopatria. A name that returns after a long gap can have multiple entries. Dotted marks show selected archaeological periods with no direct record linked here. A society can also appear through its cities, people or material culture.

Regions group entries for browsing. Border entries use their first map label point or an editorial placement. The overview expands recent centuries. Each narrower time window has a linear scale. Dates follow the build’s default chronology and each reference work’s periodization.

Border data from Bennett et al., Cliopatria (CC BY 4.0). Reference periods from the public-domain PeriodO initial collection. Map outlines from Natural Earth (public domain).
